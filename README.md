# C_Slave

<p align="center"><img src="C_Slave%20EN/icon.png" width="160" alt="C_Slave"></p>

Windows mini app (single file, no installation): your cursor becomes a whip and a little Claude critter runs away, codes like mad, watches TV on the couch and snores.

Mini aplikacja na Windows (jeden plik, bez instalacji): kursor zamienia się w pejcz, a ludzik Claude ucieka, pisze jak szalony, ogląda TV na kanapie i chrapie.
